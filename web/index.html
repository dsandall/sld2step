      Exact geometry
      Planes, cylinders, cones, NURBS and the rest are rebuilt exactly from the
      Parasolid data inside the file. Fillets (rolling-ball blends) are closely approximated.
      
    
      Assemblies too
      Component placements and names come from the assembly, so the STEP
      opens as a proper assembly tree in FreeCAD, Fusion, Onshape or any other CAD tool.
      
    
      Open source
      The same converter runs on the command line for big jobs and batches.
      Built on Open CASCADE and sldprt2xt, licensed AGPL-3.0.
