      Exact geometry
      Planes, cylinders, cones, NURBS and the rest are rebuilt exactly from the
      Parasolid data inside the file. Fillets are closely approximated (within about 0.01 mm): fine for quoting,
      fit checks and viewing.
      
    
      Assemblies too
      Component placements and names come from the assembly, so the STEP
      opens as a proper assembly tree in FreeCAD, Fusion, Onshape or any other CAD tool.
      
    
      Open source, free
      The same converter runs on the command line for big batches.
      Built on Open CASCADE and sldprt2xt, licensed AGPL-3.0. Read the code.
